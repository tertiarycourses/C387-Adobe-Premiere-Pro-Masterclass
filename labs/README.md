# Adobe Premiere Pro Masterclass — Labs

**Course code:** C387
**Version:** v12 · 21 August 2026

Each lab is self-contained. Open its folder, read the guide, and work with the supplied Premiere Pro starter project and MP4 media. Save all outputs inside the same lab folder or your trainer-approved workspace.

## Lab sequence

1. [Lab 01 — Project Setup, Ingest and Proxies](lab-01-project-ingest-proxies/README.md) — Set up a recoverable project, inspect source properties, import media into bins and attach proxies.
2. [Lab 02 — Editing Logs, Markers and Rough-Cut Plan](lab-02-logs-markers-rough-cut/README.md) — Create an editing log, mark selects and assemble a clear story spine.
3. [Lab 03 — Three-Point Editing, Trims and Pacing](lab-03-trim-pacing/README.md) — Use three-point edits and multiple trim types to produce a deliberate 25–35 second sequence.
4. [Lab 04 — Continuity, Cutaways and Transitions](lab-04-continuity-transitions/README.md) — Build a continuity sequence and use a transition only where it communicates story meaning.
5. [Lab 05 — Dialogue Repair, Music and Keyframes](lab-05-audio-repair-mix/README.md) — Repair dialogue, balance music and create smooth level automation.
6. [Lab 06 — Stills, Graphics and Adjustment Effects](lab-06-stills-graphics-effects/README.md) — Animate a still, build a readable lower third and apply a shared effect non-destructively.
7. [Lab 07 — Masks, Tracking and Visual Clean-up](lab-07-masks-stabilise-clean/README.md) — Stabilise the clip and track a feathered effect mask to clean a local imperfection.
8. [Lab 08 — Speed, Duration and Time Remapping](lab-08-speed-time-remap/README.md) — Create constant and variable speed treatments and verify motion quality.
9. [Lab 09 — Colour Correction, Shot Matching and Review](lab-09-colour-match-review/README.md) — Correct exposure and white balance with scopes, match shots and record review changes.
10. [Lab 10 — Captions, Reframe, QC and Final Export](lab-10-captions-reframe-export/README.md) — Finish titles/captions, create a vertical derivative, export verified deliverables and archive the project.
